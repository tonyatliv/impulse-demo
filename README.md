# Impulse

A standalone WebGL 2 physics playground: aim a stream of particles with your mouse and watch collisions push and rotate a central cube.

[Open the demo](https://tonyatliv.github.io/impulse-demo/)

- Move the mouse to aim; hold the pointer down to boost.
- Adjust particle flow and force with the sliders.
- Pause or reset the simulation with the buttons.

Open `index.html` in a browser supporting WebGL 2. No build step or external dependencies are required.
